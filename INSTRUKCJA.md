# Retusz — wersja testowa

Bez opłat za API. Zdjęcia przetwarzane lokalnie. Do 20 zdjęć, eksport JPG do 1800 px, bez metadanych/HDR. AI wykrywa małe obiekty jako kandydatów, nie rozumie intencji kompozycji. Gumka korzysta z lokalnego inpaint tylko jeśli pobrana wersja OpenCV je udostępnia; w przeciwnym razie wyświetla błąd, nie udaje sukcesu.

## Uruchomienie GitHub Pages

Repozytorium → Settings → Pages → Source: Deploy from a branch → main → /(root) → Save. Nie wybieraj płatnego planu. Po publikacji GitHub pokaże adres strony.

## iPhone

Otwórz adres w Safari → Udostępnij → Dodaj do ekranu początkowego. Wybierz zdjęcia, oceń korekcję, opcjonalnie uruchom wykrywanie i popraw maskę. Pobierz JPG albo serię ZIP. W Plikach rozpakuj ZIP i zapisz zdjęcia przez Udostępnij. Oryginały pozostają nienaruszone. Sesja znika po zamknięciu; najpierw pobierz wyniki.

Nie wykonano testu na fizycznym iPhonie. Pierwsza sesja: 2–3 kopie zdjęć, kontrola orientacji, koloru i eksportu. Zewnętrzne biblioteki wymagają internetu. Standardowa korekcja nie jest generatywnym AI.
